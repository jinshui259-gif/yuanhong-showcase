YUANHONG INVESTMENT

MetaCore

跨市場量化研究 App

股票、期貨與外匯的資料進入同一套研究系統。四個模型分別處理市場狀態、非線性走勢、線性關係與部位大小。

SYSTEM ARCHITECTURE

Manifold Monolith

流形單體矩陣模型

Manifold Monolith 是 MetaCore 的後端母體架構。它採用「單一統一模型」（Single Unified Model）的設計，把不同市場的資料與四個數學模型整合在同一套系統內運算。

跨市場輸入

股票、期貨與外匯的價格序列及市場特徵。

統一架構內運算

HMM、高維核回歸、簡單線性回歸與凱利公式各自處理對應的研究問題。

研究輸出

狀態機率、趨勢估計、線性關係與部位比例。

CORE MODELS

四個核心模型

前三個模型研究市場訊號。凱利公式則根據報酬假設，估算單筆交易可配置的資金比例。

市場狀態辨識

隱馬爾可夫模型（HMM）與鮑姆－韋爾奇演算法

Hidden Markov Model · Baum–Welch Algorithm

鮑姆－韋爾奇演算法從歷史價格序列估計 HMM 的參數。模型據此推估市場處於各個隱藏狀態的機率，以及狀態之間的切換規律。

非線性趨勢估計

高維核回歸

High-Dimensional Kernel Regression

依多個市場特徵的相似程度，給予歷史觀測不同權重，用來估計價格的非線性變化。以趨勢剩餘時間為預測目標時，可研究相似條件下趨勢通常還會持續多久。

線性關係檢驗

簡單線性回歸

Simple Linear Regression

每次選取一個市場特徵，估計它與後續報酬之間的線性關係。斜率描述關聯的方向與大小，可用來檢視清理過的歷史資料中是否存在微弱訊號。

資金配置

凱利公式

Kelly Criterion

根據假設的報酬分布，或勝率與盈虧幅度，估算單次交易可配置的資金比例。將結果用於槓桿評估時，還需考量估計誤差、融資成本與風險上限。
